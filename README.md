# CtrBoard-H7 AK70 MIT 正弦运动测试

基于 STM32H723 和经典 CAN 的 AK70 电机台架测试程序。电机采用 MIT 协议，在已有机械零点两侧按照正弦位置曲线往复运动。

> [!WARNING]
> 本工程仅适合空载或可靠固定的台架测试，不能直接用于穿戴测试。软件按键不能替代机械限位、硬件急停和电源切断装置。烧录前请确保电机具有足够的运动空间。

## 运行逻辑

| 操作 | 电机 | 板载 WS2812 |
| --- | --- | --- |
| 上电 | 停止，初始化 FDCAN1 并等待按键 | 红色 |
| 第一次按 KEY1 | 进入 MIT 模式，平滑增幅并等待有效反馈 | 黄色，收到反馈后变绿 |
| 再按 KEY1 | 发送零力矩停止指令并退出 MIT 模式 | 红色 |
| 初始化、反馈或位置故障 | 停止并退出 MIT 模式 | 蓝色 |

KEY1 带 20 ms 软件消抖。当前 H7 板没有独立 LED0 定义，因此使用 SPI6 驱动的板载 WS2812 显示状态。

## 控制参数

参数位于 `Algorithm/Algorithm_Example.c`。

| 参数 | 数值 |
| --- | ---: |
| 电机 ID | `1` |
| 控制周期 | `10 ms`（100 Hz） |
| 正弦周期 | `2000 ms` |
| 启动增幅时间 | `2000 ms` |
| 位置范围 | `±1.5708 rad`（±90°） |
| Kp / Kd | `25 / 1` |
| 前馈力矩 | `0 N·m` |

目标位置被限制在 ±90°；到达软件限位时，不再给出继续向外的目标速度。第一个正弦周期会从零幅值平滑增加到完整幅值，避免启动瞬间给出较大的目标速度。程序不会在启动时自动重设零点，使用前必须单独完成固定机械零点标定。

运行中连续监测反馈：启动后 100 ms 内没有收到反馈、反馈超过 50 ms 未更新、电机返回故障码，或实际位置超过 ±100°，都会发送停止与退出 MIT 指令并显示蓝色。软件保护不能替代硬件急停和机械限位。

## 当前 H7 硬件映射

原说明针对 STM32F103，不能直接复用其引脚。本工程按当前 `CtrBoard-H7_ALL.ioc` 使用以下映射：

| 功能 | 当前配置 |
| --- | --- |
| FDCAN1 RX / TX | `PD0 / PD1` |
| KEY1 | `PA15`，内部上拉，低电平按下 |
| 状态灯 | 板载 WS2812，SPI6 驱动 |
| CAN 格式 | 经典 CAN，`1 Mbit/s`，采样点 `80%` |
| MIT 反馈帧 | 标准数据帧，ID `0x001`，DLC `8` |
